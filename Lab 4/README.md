# Lab 4 — Match-3 Gem Swap Repair

This folder contains the completed Match-3 Gem Swap Repair Lab project.

## Contents

- `main.py` — game entry point.
- `game/board.py` — board logic, match handling, and gem behavior.
- `game/game_engine.py` — game state and engine logic.

## Implemented tasks

1. Invalid swaps revert without consuming a move.
2. Cascade combo multiplier for consecutive chain reactions.
3. Four-in-a-row special gems that clear a row or column when activated.
4. Idle hint indicator after five seconds without input.

## Run the game

Install Python 3.10+ and Pygame:

```bash
pip install pygame
python main.py
```

Use the mouse to select and swap adjacent gems. Press `R` to restart.
